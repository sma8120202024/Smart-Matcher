# 🔍 نظام المطابقة الذكي (Smart Matcher)

> **دقة متناهية، سرعة فائقة.. وداعاً لأخطاء المراجعة اليدوية!**

**نظام المطابقة الذكي (Smart Matcher)** هو الحل البرمجي الأسرع لمطابقة ومقارنة البيانات والجداول المالية والإدارية بدقة عالية. يعتمد البرنامج على خوارزميات ذكية لاكتشاف الفروقات، السجلات المفقودة، والتشابهات النصية في ثوانٍ معدودة، مما يختصر ساعات من المراجعة اليدوية المرهقة إلى ضغطة زر واحدة وبنسبة خطأ صفرية.

---

## ✨ المميزات الرئيسية

* ⚡ **سرعة فائقة:** معالجة ومقارنة آلاف السجلات والصفوف في لحظات دون تجميد النظام.
* 🎯 **مطابقة ذكية ومرنة:** اكتشاف التطابق التام أو الجزئي مع معالجة ذكية لاختلافات الحروف العربية (الألف، الهمزات، التاء المربوطة، والمسافات الزائدة).
* 📊 **دعم كامل لملفات Excel:** استيراد وتصدير سلس لكافة صيغ جداول البيانات (`.xlsx`, `.xls`) مع دعم كامل للترميز العربي.
* 📑 **تقارير تفصيلية فورية:** فرز تلقائي للبيانات إلى كشوفات مستقلة (السجلات المتطابقة، غير المتطابقة، المفقودة، والمكررة) جاهزة للتصدير والطباعة.
* 🖥️ **واجهة عربية عصرية:** تصميم مريح وسهل الاستخدام يدعم الشاشات عالية الدقة (High DPI).
* 🔐 **حماية وترخيص آمن:** نظام تفعيل ذكي مرتبط ببصمة الجهاز مع فترة تجريبية مجانية لمدة **7 أيام**.

---

## 💻 متطلبات التشغيل

* **نظام التشغيل:** متوافق مع كافة أنظمة ويندوز (Windows 7 SP1, Windows 8.1, Windows 10, Windows 11) للنواتين **32-bit** و **64-bit**.
* **بيئة التشغيل:** Microsoft .NET Framework 4.8 أو .NET 8.0.

---

## 🚀 طريقة الاستخدام السريعة

1. **تثبيت البرنامج:** قم بتشغيل ملف التثبيت `SmartDocumentArchive_Setup.exe` واتبع خطوات المعالج.
2. **التفعيل أو التجربة:** عند التشغيل لأول مرة، يمكنك الضغط على **"متابعة التجربة"** للاستفادة من فترة الـ 7 أيام المجانية، أو إرسال **معرّف الجهاز (Machine ID)** للمطور للحصول على مفتاح التفعيل الدائم.
3. **بدء المطابقة:**
   * اختر ملف الإكسل الأول (الأساسي) والملف الثاني (المراد مطابقته).
   * حدد أعمدة المقارنة المطلوبة.
   * اضغط على **بدء المطابقة** لاستعراض النتائج وتصدير التقرير النهائي.
